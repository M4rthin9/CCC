# ตั้งเวลานับถอยหลังเปิดรอบพิเศษ

ไปที่ **การเปิดรับจองและปฏิทิน → เปิด/ปิดการจอง** กดวันที่ในปฏิทินจนเป็น
**เปิดรอบพิเศษ** แล้วกำหนด **เริ่มเปิดรับจอง / สิ้นสุดนับถอยหลัง** และกด
**บันทึกวันที่ เวลา และข้อความ** เวลาในช่องนี้เป็นเวลาประเทศไทยเสมอ
แม้เครื่องผู้ดูแลจะใช้เขตเวลาอื่น เวลาเปิดต้องอยู่ก่อนวันเข้าใช้บริการ

หน้าแรกและหน้าปฏิทินจองแสดงวันเข้าใช้บริการ เวลาเปิด และตัวนับถอยหลัง
สำหรับแต่ละรอบที่ตั้งเวลา เมื่อครบเวลาจะเปิดวันนั้นอัตโนมัติ
การจองผ่าน API ก่อนถึงเวลาถูกปฏิเสธทั้ง VIS และ TBL
ช่วงจองล่วงหน้า โควตา และสวิตช์เปิด/ปิดแต่ละระบบยังใช้ตามเดิม

เว้นเวลาไว้หรือเลือก **ยกเลิกนับถอยหลัง / เปิดทันที** เพื่อเปิดรอบโดยไม่รอเวลา
แล้วบันทึกอีกครั้ง การล้างวันที่จะลบทั้งวันเปิดพิเศษและเวลานับถอยหลังของวันนั้น

ใช้ `admin_settings.scheduledOpenings` และ `bookingWindow.openDates` ที่มีอยู่แล้ว
ไม่ต้องย้ายฐานข้อมูล Deploy backend, dashboard และ frontend ด้วยกัน
ข้อความใหม่รองรับไทย อังกฤษ จีน และเวียดนาม รวมถึงตัวแก้ไขข้อความหลังบ้าน

ตรวจด้วย `npm run smoke:special` ที่ backend และ
`node scripts/verify-special-openings.mjs` ที่ frontend หลัง build ทั้งสองเว็บ
ชุด browser ใช้ API จำลอง ทดสอบบันทึก/โหลดเวลาไทยบนเครื่องเขตเวลาอื่น
การนับถอยหลังมือถือ/คอมพิวเตอร์ การปลดล็อกปฏิทิน และการยกเลิกเวลา
โดยไม่เปลี่ยนข้อมูลหรือส่งคำขอไปยังระบบจริง
